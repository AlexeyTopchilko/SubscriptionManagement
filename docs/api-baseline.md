# API baseline

Generated by `tools/capture-api-baseline.ps1`. **Do not edit by hand.**

A reference snapshot of every endpoint's status code and response shape, for
diffing after a change that could alter the wire contract. This is not a test
suite: nothing here asserts, and nothing fails a build.

GUIDs render as `<guid>`, timestamps as `<timestamp>` and ASP.NET correlation ids
as `<traceId>` — all three change every run and would otherwise make the diff
permanently red. Everything else is verbatim, including number formatting, which
is among the likeliest things to shift when storage changes.

To regenerate: start the API fresh, then run the script. Starting fresh matters —
storage is in-memory, so leftover mutations shift the seed data.
